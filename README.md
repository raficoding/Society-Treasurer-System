# Inventory_Management_System
A. Functional Requirements

1. Users shall be able to register/login using valid credentials.
2. The system shall validate username/email and password.
3. Users shall be able to log out securely.
4. Users shall be able to change or reset their password.
5. Admin shall be able to create, update, deactivate, and manage users.
6. Admin shall be able to assign roles and permissions.
7. The system shall allow or deny access according to assigned permissions.
8. The system shall record important login and security activities.

B. Non-Functional Requirements

1. Security: Passwords shall be securely hashed and sensitive data protected.
2. Performance: Login and authorization checks should respond quickly.
3. Reliability: Authentication should work consistently without data loss.
4. Usability: The login and account interfaces should be simple and user-friendly.
5. Availability: Authorized users should be able to access the system when required.
6. Scalability: The system should support an increasing number of users.
7. Maintainability: Authentication and authorization should be modular and easy to update.
8. Privacy: Users shall only access information permitted by their roles.
9. Accessibility: The system should be accessible to disabled users.
